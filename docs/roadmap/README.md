# Zwibba Roadmaps

This directory holds higher-level strategic roadmaps for Zwibba, distinct from the design+implementation plan pairs in `docs/plans/`. A roadmap document defines a multi-feature trajectory (e.g. production readiness, internationalisation) and references the individual plan pairs that execute it.

Current roadmaps:

- `2026-05-21-zwibba-production-roadmap.md` — three-phase trajectory from internal beta to national DRC launch
